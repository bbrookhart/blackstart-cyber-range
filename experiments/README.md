# Experiments

The v0.1 release has one flagship experiment:

| Experiment | Scenario | Controlled factor | Finding |
| --- | --- | --- | --- |
| `EXP-BS-001-v1` | `SCN-004` unauthorized setpoint mutation | Backstop OFF / ON | In the frozen synthetic model: C4 / 639.5 s unsafe → C1 / 0.0 s unsafe |

- [`EXP-BS-001/config.yaml`](EXP-BS-001/config.yaml) freezes the selected
  scientific configuration.
- [`releases/v0.1.0/`](releases/v0.1.0/) contains the canonical report,
  comparison, plots, release manifest, and both evidence packages.
- `local/` is generated by `make experiment` and ignored by git.

```bash
make bootstrap
make test
make experiment
uv run blackstart evidence verify --all --reproduce --evidence-root evidence/local
```

No finding is accepted from a scenario description or manually entered result.
Metrics must be derived from the trace, verified independently, and serialized
with provenance.
